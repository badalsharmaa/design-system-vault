## 📌 Overview

**Design System Vault** provides ready-to-use, comprehensive `DESIGN.md` documents extracted from leading modern tech, AI, fintech, luxury, and developer-first products. 

Drop any `DESIGN.md` into your project root and instruct your AI coding assistant (Antigravity, Claude Code, Cursor, Copilot, Windsurf) or Google Stitch:
> *"Build me a dashboard/landing page that matches this exact design language."*

Your AI agent will instantly adopt the exact color hierarchy, typography scales, spacing tokens, elevation systems, component states, and motion rules.

---

## 💡 What is `DESIGN.md`?

`DESIGN.md` is a plain-text markdown design system specification designed for LLMs and AI agents. It eliminates the friction of complex Figma exports or rigid JSON schemas.

| File | Read By | Purpose |
|---|---|---|
| `AGENTS.md` | Coding Agents | Architectural instructions on **how to build** the application |
| `DESIGN.md` | Design & UI Agents | Visual specifications on **how the UI should look and feel** |

## 🏗️ Structure of Each `DESIGN.md`

Every design system file in this vault captures:

```bash
├── 1. Visual Theme & Atmosphere   # Mood, density, design philosophy
├── 2. Color Palette & Roles       # Semantic hex/rgb values + functional roles
├── 3. Typography Rules            # Hierarchy, font pairings, line heights
├── 4. Component Stylings          # Buttons, inputs, modals, cards + interaction states
├── 5. Layout & Spacing            # Spacing scales, grid definitions, whitespace rules
├── 6. Depth & Elevation           # Surface hierarchy and shadow models
├── 7. Guardrails (Do's & Don'ts)  # Anti-patterns and strict design boundaries
├── 8. Responsive Strategy         # Breakpoints, mobile adaptions, touch targets
└── 9. AI Prompt Reference         # Quick copy-paste prompts for code generation
```

Each design system also includes `preview.html` and `preview-dark.html` for instant visual inspection in any browser.
